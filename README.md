# 🤖 Machine Learning Practicals

A collection of **Machine Learning practical implementations** performed using **Python and Google Colab** as part of my academic coursework.

The repository contains hands-on implementations covering various **Machine Learning algorithms, data preprocessing techniques, model training, classification, regression, and model evaluation methods**.

## 🛠️ Technologies & Tools

- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## 🎯 Objective

The objective of these practicals is to gain hands-on experience with fundamental Machine Learning concepts and understand how different algorithms can be implemented, trained, evaluated, and applied to real-world datasets.

## 🚀 How to Use

The notebooks are designed to run directly in **Google Colab**.

1. Open the required `.ipynb` notebook.
2. Open it in Google Colab.
3. Upload the required dataset, if applicable.
4. Run the cells sequentially to execute the implementation.

## 📌 Topics Covered

The practical work explores concepts including:

- Regression
- Classification
- Model Training & Testing
- Cross-Validation
- Nearest Neighbor Methods
- Support Vector Machines
- Data Preprocessing
- Model Evaluation
- Data Visualization
